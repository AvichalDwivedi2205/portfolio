# avichal.dev

Personal portfolio. Vite + React 19 + TypeScript + Motion. One page, no backend.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # -> dist/
```

Deploy: push to GitHub, import in Vercel. Framework preset auto-detects Vite. No env vars.

Content lives in `src/data.ts`. Portrait goes in `public/portrait.jpg`.
